# FlagMaster：世界國旗挑戰

## 遊戲介面改版（2026-10-14）

- 全站改為紫色星空、霓虹模式色、立體按鈕和舞台式面板；首頁為遊戲大廳。
- 主按鈕直接開始挑戰；四個模式入口為極限倒數、閃電快答、雙心生存與世界闖關。
- 國旗收藏室、辨識特訓、複習與戰績固定在底部功能列。子畫面採全螢幕呈現與自訂關閉鍵。
- 答題採大型國旗舞台、COMBO 連擊數及 2×2 答案按鍵，暫停與結算使用遊戲浮層。
- 圖鑑改為收藏卡與內嵌搜尋，小螢幕及鍵盤出現時自動減少每頁張數；保留國家位置地圖。
- 設定以遊戲、音效、規則、存檔分類；整體仍採單畫面與分頁操作，瀏覽操作保持靜音。
- 開場加入星空、發光地球與分段進場特效，遵守減少動態效果設定。

以下為先前版本的功能與設計紀錄，視覺以本次改版為準。

本次已實作 SwiftUI 原生版的首頁、答題、暫停、結算、探索紀錄與設定頁。維持五種模式與既有本機紀錄格式。

## 已實作的體驗

- 深墨綠背景、地圖網格、薄荷綠主操作、金色／珊瑚色／藍色的模式識別。
- 首頁漂浮國旗、軌道動畫、彈性按鈕、答題圖示回饋、連答與最高連答紀錄。
- 依系統「減少動態效果」及 app 設定關閉非必要動態；正誤同時使用文字與圖示。
- 探索與複習停留在答案頁，讓玩家讀出中英文名稱、觀察國旗後主動前進。
- 結算展示正確率、最高連答、選錯的名稱與正確國旗；可以只重練本局錯題。
- 探索護照顯示真實探索數、正確率與熟悉數，支援中英文搜尋和待加強篩選。
- 熟悉標準目前是「至少 3 次作答、累計正確率至少 80%」，只是產品進度指標，不等同經過驗證的長期記憶評量。
- 設定保留雙語切換，提供真正生效的觸覺與動畫開關。原音樂控制沒有對應素材，故不再展示無效的音量控制，舊偏好仍保留。

## 修正的功能

1. 答題回饋途中暫停，恢復後不再卡住；最後一題的結算也遵循暫停狀態。
2. 極速模式回饋期間不消耗下一題時間，倒數不再降到負值。
3. 切換到背景自動暫停，回來後由玩家繼續。
4. 重啟會清除舊轉場，重複點擊答案不會重複計分。
5. 複習僅納入曾答錯的國家，固定本局題池，每國一次、完成後結算。
6. 題庫原有 199 筆、197 個不同代碼。修正錯植的多明尼加（DO），合併同為 PS 的兩筆，現在為 198 個不同代碼。
7. 載入題庫時拒絕重複代碼；歷史資料解碼時避免重複 key 造成崩潰。

DO／DM 和 PS 資料核對來源：[UN M49](https://unstats.un.org/unsd/methodology/m49/)、[UNGEGN Dominican Republic](https://ungegn.un.org/dashboard/countries/details?id=214)。本次沒有全面更新其他國名、旗幟年代或政治地位。
