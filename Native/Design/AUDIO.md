# 音樂與互動音效

Native 版使用為 FlagMaster 重新設計的原創程式合成音訊，音訊隨 App 離線提供。整體方向從原先偏平緩的兒童配樂，調整為具有世界探索感的輕電子、空靈鈴音與節奏脈衝。

## 選用素材

- 首頁背景：柔和的四和弦 pad、鐵琴型分解旋律與空間回音 → `music_home.m4a`
- 答題背景：低頻脈衝、快速分解音與輕量高頻節拍 → `music_game.m4a`
- 按鈕：短促、明亮的木質敲擊感 → `sfx_tap.wav`
- 答對：兩階上行鈴音 → `sfx_correct.wav`
- 答錯／逾時：柔和下滑低音，避免過度懲罰感 → `sfx_wrong.wav`
- 完成旅程：四階上行探索鈴音 → `sfx_complete.wav`

兩首背景音樂為 160 kbps AAC；短音效保留 48 kHz PCM WAV，以減少點擊後的播放延遲。App 使用 `AVAudioSession.Category.ambient`，遵循裝置靜音設定並允許和其他音訊混合。首頁與答題音樂以淡入方式切換；暫停及成果頁會降低背景音量。

設定頁分別保存背景音樂音量、互動音效音量與觸覺回饋。Debug 畫面預覽會關閉三者，避免自動化截圖播放聲音。
